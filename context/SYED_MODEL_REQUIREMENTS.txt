6. MODEL

Per exercise, a small GRU classifier (one model each: squat, curl). This is what was validated for export.

  class FormScorer(nn.Module):
      def __init__(self, in_dim, hidden=64, num_classes=NUM_CLASSES):
          super().__init__()
          self.gru = nn.GRU(in_dim, hidden, batch_first=True)
          self.head = nn.Linear(hidden, num_classes)
      def forward(self, x):            # x: [B, 32, F]
          out, _ = self.gru(x)
          return self.head(out[:, -1]) # [B, num_classes]

  Start binary (good vs bad, NUM_CLASSES=2) using the manifest "label" column. If a class has enough clips (section 5 of Mahmoud's doc), switch to multi-class using "error_type" so the app can name the specific fault. The export I/O does not change; only NUM_CLASSES and class_labels in the model_card.

  Training notes for a small dataset:
    - set all seeds (random, numpy, torch, torch.cuda)
    - class-weighted cross-entropy (bad types will be rarer than good)
    - light augmentation on keypoints: small gaussian jitter, horizontal flip (also gives you left/right arm coverage for curl), tiny time-warp. Augmentation matters more than model size here.
    - bf16 mixed precision is fine on L4 but optional at this scale.
    - this trains in seconds; iterate on data quality, not architecture.


7. EVALUATION (the number that predicts demo success)

Split by subject_id, never by clip. Hold out 1 to 2 people entirely for validation. Report per-class precision/recall and the confusion matrix, not just accuracy (accuracy lies when classes are imbalanced). If validation collapses while training looks fine, you leaked a subject across the split. The model that generalizes to a new body is the one that survives the live demo.


8. EXPORT (Syed -> Islam contract, verified)

  import torch, coremltools as ct
  model.eval()
  example = torch.rand(1, 32, F)
  traced = torch.jit.trace(model, example)
  mlmodel = ct.convert(
      traced,
      inputs=[ct.TensorType(name="keypoint_window", shape=(1, 32, F))],
      outputs=[ct.TensorType(name="form_logits")],
      convert_to="mlprogram",
      minimum_deployment_target=ct.target.iOS17,
  )
  mlmodel.save("SquatFormScorer.mlpackage")
